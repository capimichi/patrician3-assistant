# Patrician 3 Assistant

Un assistente interattivo web per **Patrician III: L'Impero dei Mari**, progettato per aiutare i giocatori a ottimizzare le proprie rotte commerciali, calcolare la produzione delle merci, pianificare la crescita delle città e gestire l'impero commerciale della Lega Anseatica.

## 🚀 Funzionalità Previste

- **Calcolatore di Produzione**: Strumento per calcolare il consumo di materie prime e la produzione di merci finite in base al numero di laboratori/fabbriche.
- **Ottimizzatore di Rotte**: Calcolatore per stabilire i prezzi di acquisto e vendita ottimali tra le varie città anseatiche.
- **Database delle Città**: Informazioni rapide sulle merci prodotte e richieste da ogni singola città.
- **Gestore Convogli**: Calcolatore di spazio di stiva, cannoni e marinai necessari per i convogli commerciali e di scorta.

## 🛠️ Tecnologie Previste

- HTML5
- CSS3 (Variabili CSS, Grid, Flexbox, layout moderno e responsive)
- JavaScript (ES6+ Vanilla)
